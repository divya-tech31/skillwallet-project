# ResearchHub

React + Vite + TypeScript project for a collaborative research assistant UI.

## Getting started
1. Install dependencies: `npm install`
2. Copy env template: `cp .env.example .env.local` and set `VITE_GROQ_API_KEY=your_key`
3. Run dev server: `npm run dev` (open the URL printed by Vite, usually http://localhost:5173)

## Scripts
- `npm run dev` – start Vite dev server
- `npm run build` – production build to `dist/`
- `npm run preview` – preview the production build
- `npm run lint` – run ESLint
- `npm test` – run Vitest

## Tech stack
- React 18, TypeScript
- Vite 5
- Tailwind CSS + shadcn/ui
- React Router, Radix UI, TanStack Query
